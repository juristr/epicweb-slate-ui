# Demo Repo: Epic Nx Release Course

This is the demo repo used for the Nx Release course. Go to [Epic Web](https://epicweb.dev/tutorials) to take the course (it's free!!).

More useful links:

- [Nx](https://nx.dev)
- [Nx release docs](https://nx.dev/features/manage-releases)
- [Nx release recipes](https://nx.dev/recipes/nx-release)

## Repo structure

To follow along with the course the most relevant parts (given it is about a Nx, a CLI tool) is:

- configuration (mostly `nx.json`)
- the state of your Git history (especially if you use conventional commits)
- the actual commands that are run

As such the repo is structured into separate branches, which are intended as snapshots of the state & structure of the repo for each video lesson in the course.
